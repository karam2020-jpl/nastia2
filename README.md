# NASTIA BEAUTY — النسخة التجريبية الأولى

واجهة متجر عراقي عربية (RTL) للمنتجات الفاخرة، مبنية بـ Next.js وTypeScript. تشمل المتجر، الفلاتر، تفاصيل المنتج وخياراته، سلة محلية، إتمام طلب تجريبي، ولوحة إدارة تفاعلية في `/admin`.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`. وللتحقق من نسخة الإنتاج:

```bash
npm run typecheck
npm run build
npm start
```

## حدود هذه النسخة

- جميع المنتجات والطلبات والإحصاءات بيانات تجريبية موجودة في `app/data.ts` أو حالة الواجهة، ومهيأة للاستبدال بطبقة API لاحقاً.
- السلة وحدها تُحفظ في `localStorage`. بيانات العميل في نموذج الإتمام **لا تُحفظ** ولا تُرسل إلى أي خادم.
- لا يوجد دفع إلكتروني؛ الخيار المعروض هو الدفع عند الاستلام فقط.
- تأكيد الطلب محاكاة واضحة ولا ينشئ طلباً حقيقياً.
- لوحة الإدارة نموذج تفاعلي محلي. لم يُنفّذ تسجيل الدخول، الصلاحيات، حماية مسارات/خادم، التخزين الدائم، رفع الصور أو قاعدة البيانات.
- الرسومات داخل بطاقات المنتجات بدائل محايدة مولدة بـ CSS وليست صوراً لمنتجات حقيقية. كلمة `nastia` شعار نصي مؤقت لعدم توفر ملف شعار ضمن المستودع.

## المرحلة التالية

ربط قاعدة بيانات وAPI آمنين، إضافة نظام مصادقة وصلاحيات للإدارة، تخزين/رفع صور مرخّصة، التحقق الخادمي من المخزون والأسعار، وخدمة فعلية لاستقبال الطلبات وإشعاراتها.

## الحالة المشتركة في الواجهة

تدير `Providers` المنتجات ورسوم التوصيل والسلة خلال جلسة الصفحة، لذلك يظهر تعديل المنتج أو رسم المحافظة في المتجر وصفحة الإتمام فوراً. هذه الحالة تجريبية في الذاكرة وتُعاد عند تحديث الصفحة؛ السلة وحدها تُحفظ محلياً بعد التحقق من بنيتها.

إعداد Tailwind موجود في `tailwind.config.ts` و`postcss.config.mjs`، مع استمرار ملف الهوية المخصص في `app/globals.css`.
